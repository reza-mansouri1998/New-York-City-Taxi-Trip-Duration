System Architecture & Methodology

A comprehensive overview of the machine learning pipeline, geospatial engineering, containerization, and automated CI/CD deployment strategies powering the NYC Taxi Predictor.

🧠 Machine Learning Approach

The core prediction engine is built upon an optimized LightGBM Regressor. Selected for its exceptional training speed and low memory footprint in production environments, the model was trained on historical Kaggle competition data encompassing millions of New York City taxi trips.

Extensive hyperparameter tuning was conducted to manage the extrapolation constraints inherent in tree-based algorithms. The feature engineering pipeline extracts nuanced temporal patterns (day of the week, hour of the day) and transforms raw geographic coordinates into physical Haversine distances to maximize predictive accuracy.

🗺️ Geospatial Engineering

To bridge the gap between mathematical model requirements and human-centric design, the frontend utilizes advanced geospatial APIs. Leaflet.js and custom-styled CartoDB map tiles provide a responsive, restricted NYC-bounded interface.

User inputs are dynamically parsed using the Nominatim OpenStreetMap API for reverse and forward geocoding, converting clicked locations or text searches into precise coordinate points. Finally, Leaflet Routing Machine calculates real-time road routing, snapping the trip path to actual NYC streets rather than relying on geometric straight lines.

⚙️ MLOps, Containerization & CI/CD

The application follows rigorous enterprise MLOps principles. The backend is structured into modular Python components for data ingestion, transformation, and prediction pipelines, served via a Flask API wrapped in a high-performance Gunicorn production server.

To ensure total environment reproducibility and eliminate version conflicts, the system is fully containerized using a lightweight Docker image (Python 3.14-slim) with compiled C++ support (`libgomp1`) for LightGBM. Furthermore, automated software quality is maintained through Pytest unit testing and continuous integration workflows executed via GitHub Actions on every push.
