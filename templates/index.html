NYC Taxi Trip Duration Predictor

An end-to-end machine learning application designed to estimate travel times across New York City. Built with highly optimized ensemble tree models and interactive geospatial routing.

Start Prediction Platform
🧠

Advanced Machine Learning

Powered by a finely-tuned LightGBM regression model, trained on millions of historical New York City taxi records to accurately extrapolate temporal and spatial travel patterns.

🗺️

Geospatial Intelligence

Utilizes reverse geocoding via Nominatim and road-network snapping via OSRM to seamlessly translate user text inputs into precise mathematical Haversine distances.

⚙️

Modular MLOps Pipeline

Architected with strict separation of concerns, featuring dedicated modules for data ingestion, transformation, global model caching, and Flask API deployment.
